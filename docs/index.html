macOS 安装教程（仅需 3 步）

首次在 macOS 上安装应用，请按以下步骤操作

1

下载安装包

在上方「选择你的平台」中按芯片类型点击「下载 M 芯片版」或「下载 Intel 版」按钮，下载完成后双击 .dmg 安装包。

2

打开安装包

双击打开 .dmg 文件，将「瞬图优化」拖移到 Applications 文件夹。

3

首次打开

将「瞬图优化」启动后，网络提示中点击「瞬图优化」，若打开时显示安全设置警告，可点击「仍要打开」。

安装后无法打开？

  1. 在终端中执行 xattr -cr /Applications/瞬图优化.app
  2. 或者打开「系统设置」→「隐私与安全性」，找到「瞬图优化」
  3. 点击「仍要打开」按钮即可启动应用
